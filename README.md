\## Reflexão Final

1\. \*\*Qual a importância do Git para desenvolvimento de software?\*\*  

&#x20;  Permite controlar versões do código, manter um histórico seguro de alterações e trabalhar de forma organizada.

2\. \*\*Como o uso de branches pode ajudar no trabalho em equipe?\*\*  

&#x20;  Permite que várias pessoas trabalhem em funcionalidades diferentes simultaneamente sem interferir no código principal.

3\. \*\*Por que é importante escrever mensagens de commit claras?\*\*  

&#x20;  Para facilitar o entendimento das mudanças feitas ao longo do tempo por qualquer membro da equipe.

4\. \*\*Quando você usaria o arquivo .gitignore?\*\*  

&#x20;  Para evitar que arquivos temporários, senhas, chaves de API e configurações locais sejam enviados para o repositório.

5\. \*\*Como o histórico de commits do seu repositório demonstra seu aprendizado?\*\*  

&#x20;  Mostra a evolução passo a passo da construção e manipulação do projeto Git.
